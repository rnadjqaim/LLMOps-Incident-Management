# Contributing

Good first contribution areas:

- Add import adapters for existing observability tools.
- Add sample incidents.
- Improve suspected-cause scoring.
- Add Markdown or HTML report export.
- Add timeline filters in the frontend.
- Add tests for new event patterns.

## Design Principles

- Vendor-neutral by default.
- Useful without paid APIs.
- Evidence-first explanations.
- Small adapters, stable core model.
- Postmortems should be readable by engineers, product owners, and security reviewers.
